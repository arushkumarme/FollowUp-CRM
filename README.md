# FollowUp CRM

A full-stack CRM for managing leads, tracking sales opportunities, and ensuring timely customer follow-ups.

**Status:** Planning and initial development.

## Problem

Small businesses often manage potential customers using spreadsheets, chat messages, and manual reminders. FollowUp CRM aims to centralize lead management, sales pipeline tracking, customer interactions, and follow-up tasks.

## Planned Features

- **Lead Management:** Create, update, search, and filter leads.
- **Sales Pipeline:** Track leads through New, Contacted, Qualified, Proposal, Won, and Lost.
- **Follow-up Management:** Schedule the next action and identify overdue follow-ups.
- **Interaction History:** Record calls, emails, meetings, and notes.
- **Analytics Dashboard:** Track open leads, pipeline value, and conversion rates.
- **Authentication:** Protect customer data and user workspaces.
- **Automated Testing:** Verify business logic and catch regressions.

*These features are planned; they have not been implemented yet.*

## Proposed Technology Stack

- TypeScript
- Next.js
- Tailwind CSS
- PostgreSQL
- Prisma
- GitHub Actions

## Development Roadmap

1. Define requirements and data models.
2. Set up the application structure and development tools.
3. Implement lead management and validation.
4. Build the sales pipeline and interaction history.
5. Add follow-up scheduling and overdue tracking.
6. Develop analytics and reporting.
7. Implement authentication and authorization.
8. Add automated tests, CI, and deployment documentation.

## Engineering Principles

- Make small, meaningful, reviewable changes.
- Validate user input and handle errors explicitly.
- Never commit API keys, credentials, or real customer data.
- Add tests for important business rules.
- Document design decisions and known limitations.
- Prioritize product quality over commit volume.

## Project Status

The repository currently contains project documentation. Application code will be added incrementally as development progresses.
